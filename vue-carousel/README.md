# 轮播图方案总结笔记
## 一、两大类基础实现方案
### 1. 横向平移轮播（slide 滑动）
原理：所有轮播项横向排成一排，通过 `transform: translateX` 整体偏移，配合 `transition` 产生滑动效果。
- **普通循环版**：索引取模 `%`，到最后一张直接切回第0张；实现简单，末尾会硬跳转，不是连续流动。
- **假无缝循环版**：在数组末尾追加第一张图片；滑到复制图，`transitionend` 监听动画结束，关闭过渡、利用 `requestAnimationFrame` 分帧瞬移回索引 0，再开启动画，视觉连续。
- 优点：流畅滑动手感、支持拖拽；
- 缺点：无缝逻辑复杂，要处理动画开关、帧时机，容易跳动；
- 布局要点：父容器 `overflow:hidden`；容器 `display:flex`；轮播项 `flex-shrink:0`。

### 2. 淡入淡出轮播（fade）
原理：所有轮播项叠在一起（`position:absolute`），依靠 `opacity` 透明度切换，配合 `transition: opacity`。
- 循环：直接修改激活索引；基础写法很简单，不需要复制图片、瞬移。
- 优点：代码简洁，没有位移跳动问题；
- 缺点：切换时图片重叠，没有滑动连续感；处理层级 `z-index` 不当会出现覆盖 bug；拖拽交互不好做。

## 二、其他常见方案
1. **CSS 动画方案（@keyframes）**
   写固定关键帧位移/透明度动画，适合纯展示、交互少的轮播；不好控制暂停、点击切换，灵活性差。
2. **JS 动态替换 DOM / 更换图片 src**
   直接修改图片地址，没有过渡动画，生硬，一般不做带动画轮播。
3. **第三方组件库（Swiper、Element Plus Carousel 等）**
   封装好，支持滑动、淡入、无缝、拖拽、自动播放；业务开发常用，适合快速开发，学习时建议先手写理解原理。

## 三、配套通用功能（两种轮播大多都可以加）
1. 自动播放：定时器定时切换索引；鼠标移入暂停、移出继续；
2. 圆点指示器：绑定当前索引，高亮对应点位；平移无缝版需要 `%` 取模处理复制图片；
3. 上一张/下一张按钮：修改索引，边界判断（无缝方案逻辑更复杂）；
4. 过渡事件：`transitionend` 监听 CSS 过渡结束；`animationend` 监听 keyframes 动画结束。

## 四、对比选型
| 方案 | 难度 | 视觉效果 | 适合场景 |
| ---- | ---- | ---- | ---- |
| 平移普通循环 | 低 | 滑动，末尾硬跳 | 简单展示，不要求无缝 |
| 平移假无缝 | 高 | 连续流动滑动 | 商城 banner、需要顺滑滑动 |
| 淡入 fade | 低 | 渐隐渐显，图片重叠切换 | 相册、宣传图，不需要滑动感 |
| 组件库 Swiper | 很低 | 效果丰富 | 项目业务开发 |

## 五、手写轮播高频坑
1. 平移无缝：不能直接取模、同步修改状态会跳过瞬移效果、忘记关闭过渡会反向回跳；
2. 淡入：多张图重叠，注意 `z-index`，防止后一张被盖住；
3. 事件：`transitionend` 在过渡被打断时可能不触发；
4. 定时器：组件销毁一定要清除定时器，防止内存泄漏。
